# React Todo App

A modern, fully functional Todo application built with React and TypeScript. Designed for simplicity, speed, and smooth user experience.

## Features

- **Task Management**: Add, edit, and delete todos with ease.
- **Filtering**: Seamlessly switch between All, Active, and Completed tasks.
- **Status Toggling**: Mark tasks as complete or incomplete instantly.
- **Responsive UI**: Clean and minimal interface that works on any device.

## Tech Stack

- **React 18** - Core UI Library
- **TypeScript** - Static Typing for robust code
- **Vite** - Next Generation Frontend Tooling
- **Sass (SCSS)** - Advanced styling capabilities
- **Bulma** - CSS Framework for structural layouts

## Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/react-todo-app.git
   cd react-todo-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```
   *The app will be available at `http://localhost:5173` (or another port if occupied).*

## Build & Production

To generate a minified production build in the `dist` folder, run:

```bash
npm run build
```

## Testing

To run Cypress component or E2E tests (if configured):

```bash
npm run test
```
